## 🚀 Cara Menjalankan Website Secara Lokal

1. Buka folder proyek di terminal / PowerShell.
2. Jalankan HTTP server lokal:
   ```bash
   python -m http.server 8080
   ```
3. Buka browser pada alamat:
   **[http://localhost:8080](http://localhost:8080)**

## 📁 Struktur Halaman
- **`index.html`** : Halaman Beranda (Hero Banner, Widget Sholat Real-Time, Menu Cards, Quick Infaq).
- **`sejarah.html`** : Sejarah & Transformasi (3-Card Journey Grid, Tujuan & Visi-Misi).
- **`takmir.html`** : Struktur Takmir (Pimpinan Inti, Filter Kategori, Grid Pengurus).
- **`jadwal-sholat.html`** : Jadwal Sholat 5 Waktu Real-Time (Hisab Kemenag RI, Countdown Timer).
- **`infaq.html`** : Layanan Infaq & Sedekah (Buku Tabungan Bank BPD DIY No. `024.231.001470`).
- **`agenda.html`** : Agenda & Program Ibadah (Sholat 5 Waktu, Sholat Jumat, Majelis Taklim, Qurban).
- **`fasilitas.html`** : Fasilitas & Galeri Dokumentasi (5 Sarana Utama, Lightbox Modal).
- **`kontak.html`** : Peta Lokasi Google Maps Presisi, Form Pesan WhatsApp Takmir, FAQ.
